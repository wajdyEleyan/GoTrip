Über GoTrip

GoTrip ist eine mobile Web-App für die gemeinsame Gruppenreiseplanung. Gruppen koordinieren Verfügbarkeiten, Budgets und Interessen — die App berechnet daraus automatisch einen Score für jeden Reisevorschlag, basierend auf echten Klimadaten, Biodiversitätsdaten und NASA-Satellitendaten.

KI-Score (40 %) + Gruppen-Sternebewertung (60 %) = Hybrid-Score

Wer Strand wählt und Frankfurt vorschlägt, bekommt einen niedrigen Score — weil Frankfurt im Binnenland liegt (echte Küstendaten via Open-Meteo Marine API).

Installation & lokaler Start

1. Repository klonen

git clone https://github.com/mo518525/Trip-Planer.git
cd Trip-Planer

2. Frontend starten

npm install
npm run dev
# → http://localhost:5173

3. Backend starten

cd server
npm install
node index.js
# → http://localhost:3001

4. Umgebungsvariablen (server/.env)

DATABASE_URL=postgresql://...    # Neon PostgreSQL Connection String
EARTHDATA_TOKEN=...              # NASA Earthdata Bearer Token (optional)

server/.env ist in .gitignore — wird nie ins Repository committed.

KI-Score-Berechnung

Gesamtscore = Klimakomfort × 0,4 + Interessenerfüllung × 0,6

Klimakomfort (ERA5):
  Temperatur 20–26 °C   → +25 Punkte
  Niederschlag < 20 mm  → +12 Punkte
  Sonne ≥ 9 h/Tag       →  +8 Punkte

Interessenerfüllung (Geocoding + Marine API):
  beach   → !coastal ? 8 : (warm ? 95 : 65)
  city    → pop ≥ 500.000 ? 92 : 18
  nature  → species > 1.000.000 ? 85 : 55
