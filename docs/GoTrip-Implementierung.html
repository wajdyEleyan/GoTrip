1. Entwicklungs-Fundament

1.1 Haupt-Komponenten und Funktionen

GoTrip ist eine mobile Web-App für die gemeinsame Gruppenreiseplanung. Die Anwendung besteht aus 16 Screens (Seiten), die jeweils einer eigenen Route entsprechen, sowie einer Reihe wiederverwendbarer Komponenten und Dienste. 1.3 Nutzungskontext und Ansichten

GoTrip ist ausschließlich als Mobile-Anwendung konzipiert. Die App richtet sich an junge Erwachsene (Personas: Leon, 22 J.; Maya, 25 J.), die unterwegs in einer Gruppe eine Reise planen. Der Nutzungskontext ist mobil — auf dem Smartphone, häufig in der Gruppe oder in öffentlichen Verkehrsmitteln.

Die Mobile-Ansicht hat uneingeschränkten Vorrang. Das Layout verwendet eine feste maximale Breite von 430 px (entspricht einem Standard-Smartphone), eine fixierte Bottom-Navigation, native iOS-ähnliche Steuerelemente (Wheel-Date-Picker, Bottom-Sheets, Swipe-Gesten) und Touch-optimierte Schaltflächen. Eine Tablet- oder Desktop-Ansicht ist nicht vorgesehen; die App ist jedoch im Browser aufrufbar und skaliert auf größeren Bildschirmen innerhalb der mobilen Maximalbreite zentriert.

1.4 Datenquellen und API-Endpunkte

GoTrip nutzt mehrere externe Datenquellen für die KI-Score-Berechnung. Alle Anfragen an kostenpflichtige oder CORS-beschränkte APIs werden über den eigenen Express-Server (server/index.js) als Proxy weitergeleitet:

Tabelle 3: Externe Datenquellen und API-Endpunkte
DatenquelleAPIVerwendungszweckKosten
Klimadaten (ERA5)Open-Meteo Climate APITemperatur, Niederschlag, Sonnenstundenkostenlos
KüstenerkennungOpen-Meteo Marine APIStrandeignung: Meerestemperatur, Wellengangkostenlos
GeocodingOpen-Meteo Geocoding APIStadtname → Koordinatenkostenlos
BiodiversitätGBIF Occurrence APIArtenvielfalt am Reisezielkostenlos
Wetterdaten (NASA)NASA POWER APIHistorische Sonneneinstrahlungkostenlos
SatellitendatenNASA Earthdata MODISLandnutzung, VegetationsindexToken erforderlich

Die Score-Berechnung kombiniert Klimakomfort (40 %) und Interessenerfüllung (60 %):

Gesamtscore = Klimakomfort × 0,4 + Interessenerfüllung × 0,6 Klimakomfort (ERA5): Temperatur 20–26 °C → +25 Punkte Niederschlag < 20 mm → +12 Punkte Sonne ≥ 9 h/Tag → +8 Punkte Interessenerfüllung (je nach gewähltem Interesse): Strand (beach) → küstennahe Stadt? Ja → 85–95 Pkt., Nein → 8 Pkt. Stadt (city) → Einwohner ≥ 500.000? Ja → 92 Pkt., Nein → 18 Pkt. Natur (nature) → GBIF-Arten > 1.000.000? Ja → 85 Pkt., Nein → 55 Pkt.
Hinweis: Der NASA-Earthdata-Token wird in server/.env als Umgebungsvariable (EARTHDATA_TOKEN) gespeichert und ist in .gitignore aufgeführt — er wird nie in das Repository committed.

2. Implementierung

2.1 Systemübersicht

GoTrip wurde als Progressive Web App (PWA) mit React 19 und TypeScript implementiert. Das Frontend kommuniziert mit dem Express-Backend über REST-Endpunkte. Für die Echtzeit-Synchronisation zwischen Gruppenmitgliedern wird HTTP-Polling im 6-Sekunden-Intervall eingesetzt (src/services/tripSync.ts). Die Datenbank liegt in der Cloud (Neon PostgreSQL); das Backend läuft auf Render.com.
